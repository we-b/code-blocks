# 規程・マニュアルドラフト生成

規程名「$0」、改定要点「$1」の改定案の下書きを作成してください。

## 出力構成

1. 改定の背景（3行以内。法改正・制度変更・運用上の課題のいずれかを明記）
2. 新旧対照の要点（変わる点を箇条書きで3〜5点）
3. 改定条文の案（該当条項のみ。法令の原文確認が必要な箇所は「（要確認）」を付ける）
4. 社内周知文の案（全社員向け、5行以内、施行日と問い合わせ先の欄を設ける）

法令名・施行日など事実に関わる部分は断定せず、確認を促す表現にすること。
