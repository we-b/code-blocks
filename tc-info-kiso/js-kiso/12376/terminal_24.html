==> mysql@8.0
We've installed your MySQL database without a root password. To secure it run:
    mysql_secure_installation

MySQL is configured to only allow connections from localhost by default

To connect run:
    mysql -uroot

mysql@8.0 is keg-only, which means it was not symlinked into /home/linuxbrew/.linuxbrew,
because this is an alternate version of another formula.

If you need to have mysql@8.0 first in your PATH, run:
  echo 'export PATH="/home/linuxbrew/.linuxbrew/opt/mysql@8.0/bin:$PATH"' >> ~/.profile

For compilers to find mysql@8.0 you may need to set:
  export LDFLAGS="-L/home/linuxbrew/.linuxbrew/opt/mysql@8.0/lib"
  export CPPFLAGS="-I/home/linuxbrew/.linuxbrew/opt/mysql@8.0/include"

For pkg-config to find mysql@8.0 you may need to set:
  export PKG_CONFIG_PATH="/home/linuxbrew/.linuxbrew/opt/mysql@8.0/lib/pkgconfig"


To restart mysql@8.0 after an upgrade:
  brew services restart mysql@8.0
Or, if you don't want/need a background service you can just run:
  /home/linuxbrew/.linuxbrew/opt/mysql@8.0/bin/mysqld_safe --datadir=/home/linuxbrew/.linuxbrew/var/mysql
