# コードレビュー

## レビュー対象
$ARGUMENTS

## レビュー観点
以下の観点でコードをレビューしてください。

### 1. コード品質
- [ ] 可読性: 変数名、関数名は適切か
- [ ] 保守性: コードは理解しやすいか
- [ ] 重複: DRY原則に従っているか
- [ ] 複雑度: 関数の複雑度は適切か

### 2. バグ・エラー
- [ ] ヌル参照: null/undefinedのチェックは適切か
- [ ] エッジケース: 境界値の処理は正しいか
- [ ] エラーハンドリング: 例外処理は適切か

### 3. セキュリティ
- [ ] 入力検証: ユーザー入力は検証されているか
- [ ] SQLインジェクション: クエリは安全か
- [ ] XSS: 出力はエスケープされているか
- [ ] 認証・認可: アクセス制御は適切か

### 4. パフォーマンス
- [ ] N+1問題: データベースクエリは最適化されているか
- [ ] メモリ: メモリリークの可能性はないか
- [ ] ループ: 不要な繰り返し処理はないか

## 出力形式
各観点について、以下の形式でレポートを作成してください。

- ✅ 問題なし
- ⚠️ 警告（改善推奨）
- ❌ 問題あり（要修正）

具体的なコード箇所と改善案を含めてください。
