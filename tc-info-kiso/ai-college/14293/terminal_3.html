  4. その他の改善提案

  4-1. エラーハンドリングの統一

  現在 duplicate アクションのみ rescue でエラーハンドリングしていますが、他のアクション（update, destroy など）では select_task
  で同様のエラーが発生する可能性があります。

  # ApplicationControllerに共通のエラーハンドリングを追加
  class ApplicationController < ActionController::Base
    rescue_from ActiveRecord::RecordNotFound, with: :record_not_found

    private

    def record_not_found
      render json: { error: 'Record not found' }, status: :not_found
    end
  end

  4-2. サービスクラスの責務明確化

  ServiceResult の success? が false の場合のハンドリングがコントローラーにありません。

  # コントローラーで結果をチェック
  def duplicate
    result = Tasks::DuplicateService.new(params[:id]).call
    if result.success?
      tasks_all
    else
      render json: { errors: result.errors }, status: :unprocessable_entity
    end
  rescue ActiveRecord::RecordNotFound
    render json: { error: 'Task not found' }, status: :not_found
  end
