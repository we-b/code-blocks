Articles APIのリクエストスペックを書いてください。
以下のエンドポイントをテストしてください：

1. GET /api/v1/articles（一覧取得）
   - 記事一覧が取得できること
   - ステータスコードが200であること

2. GET /api/v1/articles/:id（詳細取得）
   - 記事の詳細が取得できること
   - 存在しないIDの場合は404を返すこと

3. POST /api/v1/articles（作成）
   - 正しいパラメータで記事が作成できること
   - 不正なパラメータでは422を返すこと

4. PATCH /api/v1/articles/:id（更新）
   - 記事を更新できること
   - 存在しないIDの場合は404を返すこと

5. DELETE /api/v1/articles/:id（削除）
   - 記事を削除できること
   - 存在しないIDの場合は404を返すこと

テストファイルは spec/requests/api/v1/articles_spec.rb に作成してください。
JSONレスポンスの検証も含めてください。
