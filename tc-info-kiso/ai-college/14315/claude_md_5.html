# 禁止事項

## 絶対に編集しないファイル
- .env, .env.* - 環境変数ファイル
- package-lock.json, yarn.lock - 依存関係のロックファイル
- *.config.js の設定値 - プロジェクト設定
- migrations/ - データベースマイグレーション

## 実行しないコマンド
- rm -rf - 再帰的削除（誤削除防止）
- git push --force - 強制プッシュ（履歴破壊防止）
- DROP TABLE/DATABASE - データベース削除

## 変更前に確認が必要
- API エンドポイントの変更
- データベーススキーマの変更
- 認証・認可に関するコード
