# コーディング規約

## 命名規則
- 変数名・関数名: キャメルケース（例: getUserById）
- 定数: アッパースネークケース（例: MAX_RETRY_COUNT）
- クラス名: パスカルケース（例: UserService）
- ファイル名: ケバブケース（例: user-service.ts）

## コードスタイル
- インデント: スペース2つ
- 引用符: シングルクォート
- セミコロン: 必須
- 行の長さ: 最大100文字
- 末尾カンマ: 必須

## コメント
- 関数には必ずJSDocを付ける
- 複雑なロジックには説明コメントを付ける
- TODOコメントには担当者名を含める（例: // TODO(yamada): ）

## エラーハンドリング
- try-catchで必ずエラーをキャッチする
- エラーログは適切なレベル（error/warn/info）で出力する
- ユーザー向けエラーメッセージは日本語で分かりやすく
