# 企画書ドラフト生成

企画テーマ「$0」、ターゲット「$1」のプロモーション企画書の下書きを作成してください。

## 出力構成
1. 企画の狙い（3行以内）
2. ターゲットとインサイト（ターゲットが抱える状況・気持ちを2〜3点）
3. 施策案（3案。それぞれ概要・チャネル・期待効果を1行ずつ）
4. 想定KPI（認知・反応・購買の3段階で1つずつ）
5. 発信文のドラフト（SNS投稿文140字以内、プレスリリース冒頭3行）

数値や実績は仮置きとし、「（仮）」と明記すること。
