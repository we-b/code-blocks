# 春の新生活キャンペーン 企画書（ドラフト）
## 1. 企画の狙い
新生活を始める20代単身世帯に、初期費用を抑えて生活を整えられる選択肢として認知を獲得する。
## 2. ターゲットとインサイト
- 引っ越し直後で出費が重なり、価格に敏感
- 情報収集はSNS中心。比較サイトより口コミを信頼
- 「最低限そろえたい」と「少しは気に入ったものを」の間で揺れている
## 3. 施策案
- 案A：新生活セット割（自社EC、期間限定）／期待効果：客単価の底上げ（仮）
- 案B：引っ越し日投稿キャンペーン（Instagram）／期待効果：UGC獲得（仮）
- 案C：不動産会社との入居者向け特典連携／期待効果：新規流入（仮）
