  アプリケーション概要

  このアプリは タスク管理のバックエンドREST API で、Spring Boot 3.xで構築されたJSONを返すAPIです。

  ---
  データ構造

  genres テーブル
  - id (Long, PK, AUTO) - ジャンルID
  - name (String, NOT NULL) - ジャンル名
  - created_at / updated_at - タイムスタンプ

  tasks テーブル
  - id (Long, PK, AUTO) - タスクID
  - title (String, NOT NULL) - タスクのタイトル
  - content (String) - タスクの詳細内容
  - status (String) - ステータス（todo / doing / done）
  - genre_id (Long, FK) - ジャンルID
  - created_at / updated_at - タイムスタンプ

  リレーション
  - Genre has many Tasks
  - Task belongs to Genre (ManyToOne)

  ---
  API エンドポイント

  Tasks API
  - GET    /tasks       - タスク一覧取得
  - GET    /tasks/{id}  - タスク詳細取得
  - POST   /tasks       - タスク作成
  - PUT    /tasks/{id}  - タスク更新
  - DELETE /tasks/{id}  - タスク削除

  Genres API
  - GET    /genres      - ジャンル一覧取得
  - POST   /genres      - ジャンル作成
  - DELETE /genres/{id} - ジャンル削除
