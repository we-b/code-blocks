# Task Checker API

## プロジェクト概要
タスク管理のバックエンドREST API

## 技術スタック
- Java 17
- Spring Boot 3.x
- Gradle（ビルドツール）
- H2 Database（インメモリDB）
- JUnit 5 + Mockito（テスト）

## 開発ルール

### 一般
- テストは必ず書く（JUnit 5）
- コミットメッセージは日本語で記述

### バリデーション
- エラーメッセージは日本語で記述

### テスト規約
- テストクラス名: 対象クラス名 + Test（例: TaskControllerTest）
- @DisplayNameで日本語のテスト名を付ける
- @Nestedでテストをグループ化する
