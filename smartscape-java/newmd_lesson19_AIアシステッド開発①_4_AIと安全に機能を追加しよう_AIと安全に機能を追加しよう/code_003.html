  アプリケーション概要

  このアプリは タスク管理のバックエンドREST API で、Spring Boot 3.xで構築されたJSONを返すAPIです。

  ---
  データ構造

  genres テーブル
  - id (Long, PK, AUTO) - ジャンルID
  - name (String, NOT NULL) - ジャンル名
  - created_at / updated_at - タイムスタンプ

  tasks テーブル
  - id (Long, PK, AUTO) - タスクID
  - name (String, NOT NULL) - タスクの名前
  - explanation (String) - タスクの詳細説明
  - status (Integer) - ステータス（0=未開始, 1=計画, 2=進行中, 3=実装, 4=テスト, 5=要件定義）
  - deadline_date (Timestamp) - 期限日
  - genre_id (Long, FK) - ジャンルID
  - created_at / updated_at - タイムスタンプ

  リレーション
  - Genre has many Tasks
  - Task belongs to Genre (ManyToOne)

  ---
  API エンドポイント

  Tasks API
  - GET    /api/tasks/               - タスク一覧取得
  - GET    /api/tasks/{taskId}/      - タスク詳細取得
  - POST   /api/tasks/               - タスク作成
  - PUT    /api/tasks/{taskId}/update  - タスク更新
  - DELETE /api/tasks/{taskId}/delete - タスク削除

  Genres API
  - GET    /api/genres/              - ジャンル一覧取得
  - POST   /api/genres/              - ジャンル作成
  - DELETE /api/genres/{genreId}/delete - ジャンル削除
