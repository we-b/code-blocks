◎ やりたいこと
Makeで、Excel Onlineの在庫データから単価が50000円以上の商品を絞り込み、
その商品の情報（商品名、単価、在庫数）を確認できるシナリオを作成したい。

◎ 現状
・Excel OnlineのOneDrive上にあるファイル「商品一覧.xlsx」を使用
・データはテーブル形式（テーブル名：在庫管理）で、列構成は以下の通り
　日付 / 商品名 / 在庫数 / 単価 / 金額 / 仕入先
・Makeの無料プランを使用中
・Makeのアカウントは作成済みで、Excel Onlineとのコネクションも設定済み
