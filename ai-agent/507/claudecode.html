作成するファイル:
competitor-analysis/.claude/skills/competitor-analysis/SKILL.md

SKILL.mdの要件:
1. フロントマター:
   - name: competitor-analysis
   - description: SaaS競合プロダクトの価格・機能比較分析を自動実行するワークフロー。ユーザーが「競合分析」「競合比較」「プロダクト比較」「competitor analysis」「SaaS比較」と言った時に使用。config.jsonの設定に基づき、Webクロール、データ構造化、スキーマバリデーション、差分計算、CSV生成、インフォグラフィック生成、分析レポート作成、Viewerでの人間レビューまでの全工程を統括する。

2. 本文の構成:
   - ワークフローの全10ステップを命令形で記述
   - 各ステップで使うスクリプトの具体的なパスとコマンド
   - Claude Code自身がやる処理（クロール、構造化、レポート生成）とスクリプトに委譲する処理の区別を明記
   - 各ステップの成功条件（何をもって次のステップに進むか）
   - エラーハンドリング（各ステップでの失敗時の対処法）
   - 使用例（通常実行、オプション付き実行）

3. 執筆ルール:
   - 命令形で書く
   - 「なぜ」を説明する（理由を伝えることで想定外の状況にも対応できる）
   - 具体的なコマンドやファイルパスを含める
   - 500行以内に収める

4. ワークフローの10ステップ:
   ステップ1: config.json を読み込み、対象企業とURLを確認する
   ステップ2: Playwright MCP で各企業の料金ページをクロールする
   ステップ3: クロールしたテキストを構造化JSONに変換する（data/current/ に保存）
   ステップ4: python .claude/skills/competitor-analysis/scripts/validate-schema.py で各JSONのスキーマを検証する
   ステップ5: python .claude/skills/competitor-analysis/scripts/compare-data.py で前回データとの差分を計算する
   ステップ6: python .claude/skills/competitor-analysis/scripts/generate-csv.py で比較マトリクスCSVを生成する
   ステップ7: python .claude/skills/competitor-analysis/scripts/generate-image.py でインフォグラフィックを生成する
   ステップ8: data/output/comparison.json を分析し、data/output/report.md を生成する
   ステップ9: cd viewer && npm run dev でViewerを起動し、ユーザーにレビューを促す
   ステップ10: ユーザーの承認/差し戻しに基づいて、必要に応じて再生成する

既存のスクリプト（.claude/skills/competitor-analysis/scripts/ 内）の内容を読み込んで、正確なコマンドライン引数を反映してください。
