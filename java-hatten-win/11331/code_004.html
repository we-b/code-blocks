■解決したいこと
PictweetのLikeControllerのcreateメソッドでいいねを保存する際に、

java.lang.NullPointerException: Cannot invoke "com.example.pictweet.entity.Post.getId()"
because the return value of "com.example.pictweet.entity.Like.getPost()" is null

とエラーが表示される。

■自力で調べた内容
NullPointerExceptionについてカリキュラムで確認した。
@ManyToOneアノテーションの使い方をカリキュラムで確認した。
https://master.tech-camp.in/curriculums/00000

■仮説と検証作業の結果
「the return value of Like.getPost() is null」と表示されたので、LikeエンティティのPostへの関連付けが正しく設定されていないと判断した。カリキュラムの@ManyToOneの記述と見比べたが、間違った箇所は無かった。
