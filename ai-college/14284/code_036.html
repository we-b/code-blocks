Articleモデルのstatusカラムにenumを設定したいです。
以下の選択肢について、深く検討してください。

【選択肢】
1. 通常のenum（enum status: { draft: 0, published: 1, archived: 2 }）
2. _prefix付きenum（enum status: { draft: 0, published: 1, archived: 2 }, _prefix: true）
3. _suffix付きenum（enum status: { draft: 0, published: 1, archived: 2 }, _suffix: true）

【検討してほしいこと】
- 各選択肢で生成されるメソッド名
- 他のカラムにもenumを追加した場合の影響
- 実際のコードでの使い勝手
- どの選択肢が最も適切か、理由とともに

think deeply about the pros and cons of each approach
