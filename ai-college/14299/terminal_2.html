  ---
   Critical: セキュリティ

  Task.all は認証・認可のチェックがありません。ユーザー自身のタスクのみ表示する場合、重大なセキュリティホールになります。

  # 修正案
  def index
    @tasks = current_user.tasks
  end

  ---
  High: パフォーマンス

  N+1クエリのリスク: ビューで関連モデルにアクセスする場合、includes が必要です。

  @tasks = Task.includes(:user)

  大量データ対策: ページネーション未実装だと、データ量が増えた際にメモリ問題が発生します。

  @tasks = Task.page(params[:page])  # kaminari使用

  ---
   Low: コードスタイル

  1行での記述は可読性が低いため、複数行推奨です。

  # Before
  def index; @tasks = Task.all; end

  # After
  def index
    @tasks = Task.all
  end

  ---
  推奨コード例

  def index
    @tasks = Task
      .for_user(current_user)
      .includes(:user)
      .page(params[:page])
  end
