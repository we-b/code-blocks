## Articleモデルの設計案

### 1. カラム定義

| カラム名      | 型         | 制約                  | 説明               |
|--------------|-----------|----------------------|-------------------|
| title        | string    | NOT NULL             | タイトル           |
| body         | text      | NOT NULL             | 本文               |
| status       | integer   | NOT NULL, default: 0 | ステータス（enum）   |
| published_at | datetime  | -                    | 公開日時           |

### 2. enum設計

statusカラムには、以下の値を設定します：
- draft (0): 下書き状態
- published (1): 公開状態
- archived (2): アーカイブ状態

### 3. バリデーションルール

titleカラム:
- 必須入力
- 1〜100文字

bodyカラム:
- 必須入力

statusカラム:
- enumの範囲内

published_atカラム:
- statusがpublishedの場合は必須

### 4. 将来の拡張性

カテゴリやタグを追加する場合は、以下の方法が考えられます：
- Category: 1対多の関連（article belongs_to category）
- Tag: 多対多の関連（has_many through）
