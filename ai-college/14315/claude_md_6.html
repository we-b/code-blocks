# プロジェクト概要
社内の勤怠管理システムのバックエンドAPIです。

## 技術スタック
- 言語: TypeScript 5.x
- ランタイム: Node.js 20.x
- フレームワーク: Express 4.x
- データベース: PostgreSQL 15.x
- ORM: Prisma 5.x
- テスト: Jest

## ディレクトリ構造
- src/controllers/ - HTTPリクエストハンドラ
- src/services/ - ビジネスロジック
- src/repositories/ - データアクセス
- src/middlewares/ - ミドルウェア
- src/utils/ - ユーティリティ関数

# コーディング規約
## 命名規則
- 変数・関数: camelCase
- 定数: UPPER_SNAKE_CASE
- クラス: PascalCase
- ファイル: kebab-case.ts

## コードスタイル
- インデント: スペース2つ
- 引用符: シングルクォート
- セミコロン: 必須
- 末尾カンマ: 必須

## コメント
- 関数にはJSDocを付ける
- 複雑なロジックには説明を付ける

# 禁止事項
## 編集禁止
- .env, .env.*
- prisma/migrations/
- package-lock.json

## 実行禁止
- rm -rf
- git push --force
- npx prisma migrate（手動管理）

## 避けるべきパターン
- any型の使用
- console.log（loggerを使用）
- ハードコードされた値
