# 禁止事項

## 絶対に編集してはいけないファイル
- .env.production（本番環境の設定）
- docker-compose.prod.yml（本番用Docker設定）
- migrations/（DBマイグレーションファイル）

## 実行してはいけないコマンド
- rm -rf（再帰的削除）
- DROP TABLE / DROP DATABASE
- git push --force to main

## 避けるべきパターン
- console.logを本番コードに残さない
- anyTypeScriptで型を指定する（型安全性を保つ）
- ハードコードされた認証情報
