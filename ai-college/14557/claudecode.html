competitor-analysis/.claude/skills/competitor-analysis/scripts/compare-data.py を作成してください。

仕様:
- 入力:
  - data/current/*.json（今回の構造化データ）
  - data/previous/*.json（前回の構造化データ）
- 処理:
  - 同じ企業名のJSONファイル同士を比較
  - 各プランのフィールドごとに差分を計算:
    - 数値フィールド（priceValue）: 差分値と変化率を計算
    - テキストフィールド（features, limitations）: 追加・削除された項目を検出
    - プラン自体の追加・削除を検出
- 出力: data/output/comparison.json
- 出力形式:
  {
    "comparedAt": "YYYY-MM-DDTHH:mm:ss",
    "companies": [
      {
        "name": "企業名",
        "plans": [
          {
            "name": "プラン名",
            "changes": {
              "priceValue": {
                "previous": 前回値,
                "current": 今回値,
                "diff": 差分,
                "changeRate": 変化率（%）
              },
              "features": {
                "added": ["追加された機能"],
                "removed": ["削除された機能"],
                "unchanged": ["変化なしの機能"]
              },
              "limitations": {
                "added": ["追加された制限"],
                "removed": ["削除された制限"],
                "unchanged": ["変化なしの制限"]
              }
            }
          }
        ]
      }
    ]
  }
- コマンドライン引数:
  - --current-dir: 今回データのディレクトリ（デフォルト: data/current/）
  - --previous-dir: 前回データのディレクトリ（デフォルト: data/previous/）
  - --output: 出力先（デフォルト: data/output/comparison.json）
- 初回実行時（previousが空の場合）:
  - currentの各JSONファイルをpreviousにコピー
  - 差分はすべてゼロ（変化なし）として出力
  - ターミナルに「初回実行: previousデータを作成しました」と表示
