【悪い例】インスタンスを作成する際にマジックナンバーを用いて値を代入している
// コードを見ただけでは「type: 1」がどういった商品タイプを示しているのか分からない
const newProduct = await prisma.product.create({ data: {name: 'hogehoge', type: 1 }});

【良い例】コメントアウトで数字の説明をしている
// type: 1は日本産の商品
const newProduct = await prisma.product.create({ data: {name: 'hogehoge', type: 1 }});

【良い例】定数を定義して値を代入していて、コードを読むだけで「type: 1」が日本に関連した商品であることがわかる
const JAPANESE_PRODUCT_TYPE = 1;
const newProduct = await prisma.product.create({ data: {name: 'hogehoge', type: JAPANESE_PRODUCT_TYPE }});
