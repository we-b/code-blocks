competitor-analysis/data/current/ にある各企業の生テキストファイル（*-raw.txt）を読み取り、構造化されたJSONファイルに変換してください。

参照:
- competitor-analysis/config.json の extractFields（plans, price, features, limitations）を抽出するフィールドとして使用

出力形式:
各企業ごとに以下の形式のJSONファイルを生成してください:

{
  "company": "企業名",
  "url": "取得元URL",
  "collectedAt": "YYYY-MM-DDTHH:mm:ss",
  "data": {
    "plans": [
      {
        "name": "プラン名",
        "price": "月額料金（文字列）",
        "priceValue": 数値（月額料金の数値のみ。元の通貨のまま。無料の場合は0）,
        "features": ["機能1", "機能2", ...],
        "limitations": ["制限事項1", "制限事項2", ...]
      }
    ]
  }
}

出力先: competitor-analysis/data/current/{企業名小文字}.json
（例: notion.json, todoist.json, asana.json）

注意:
- 価格がドル表記の場合は、price に「$10」のように元の表記をそのまま記録し、priceValue には数値だけ（例: 10）を入れてください。為替レートでの円換算はしません（為替レートは日々変動するため、換算した数値を保存すると、同じ生データから作り直しても日によって値が変わってしまうからです。生データに忠実な、決定的なデータにするためです）
- ※異なる通貨の priceValue を、そのまま大小比較することはできません。通貨をまたいだ比較は、price（表記）とあわせて人間が解釈する前提です
- 「要問合せ」など金額が公開されていないプランは、priceValue を null にしてください
- 無料プランも含めてください
- 情報が読み取れないフィールドは null にしてください
- 各プランの features と limitations はできるだけ多く抽出してください
