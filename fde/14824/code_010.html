[最初]
  is_playing = True

[1周目: while の条件チェック]
  is_playing は True → ループの中身を実行
  じゃんけんする → 結果「あいこ」
  あいこの分岐に入る → is_playing はそのまま True

[2周目: while の条件チェック]
  is_playing はまだ True → ループの中身を実行
  じゃんけんする → 結果「勝ち」
  勝ちの分岐に入る → is_playing = False ★ここで書き換わる

[3周目? 条件チェック]
  is_playing は False → ループから抜ける（プログラム終了）
