competitor-analysis/.claude/skills/competitor-analysis/scripts/compare-data.py を作成してください。

仕様:
- 入力:
  - data/current/*.json（今回の構造化データ）
  - data/previous/*.json（前回の構造化データ）
- 突合キー（どれを同一とみなすか）:
  - 企業の対応づけ: JSON内の company フィールド（無ければファイル名）で行う
  - プランの対応づけ: プランの name で行う（名前が一致するプランを「同一プラン」とみなす。名前が変わった場合は削除＋新規として扱う）
- 処理:
  - 同じ企業（companyが一致するJSON）同士を比較
  - 各プランのフィールドごとに差分を計算:
    - 数値フィールド（priceValue）: 差分値と変化率を計算
      - 変化率 = (今回 − 前回) ÷ 前回 × 100（小数第1位まで）
      - 前回が 0、または前回・今回いずれかが null（要問合せ）の場合は changeRate を null とし、diff のみ算出する（前回0→有料化、要問合せ→有料化 などは「新規価格設定」として別途検出）
    - テキストフィールド（features, limitations）: 追加・削除された項目を検出
    - プラン自体の追加・削除を検出（name をキーに、片方にしかない name を追加／削除とする）
- 出力: data/output/comparison.json
- 出力形式:
  {
    "comparedAt": "YYYY-MM-DDTHH:mm:ss",
    "companies": [
      {
        "name": "企業名",
        "plans": [
          {
            "name": "プラン名",
            "changes": {
              "priceValue": {
                "previous": 前回値,
                "current": 今回値,
                "diff": 差分,
                "changeRate": 変化率（%）
              },
              "features": {
                "added": ["追加された機能"],
                "removed": ["削除された機能"],
                "unchanged": ["変化なしの機能"]
              },
              "limitations": {
                "added": ["追加された制限"],
                "removed": ["削除された制限"],
                "unchanged": ["変化なしの制限"]
              }
            }
          }
        ]
      }
    ]
  }
- コマンドライン引数:
  - --current-dir: 今回データのディレクトリ（デフォルト: data/current/）
  - --previous-dir: 前回データのディレクトリ（デフォルト: data/previous/）
  - --output: 出力先（デフォルト: data/output/comparison.json）
- 初回実行時（previousが空の場合）:
  - currentの各JSONファイルをpreviousにコピー
  - 差分はすべてゼロ（変化なし）として出力
  - ターミナルに「初回実行: previousデータを作成しました」と表示
