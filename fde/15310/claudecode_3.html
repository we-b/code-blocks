competitor-analysis/.claude/skills/competitor-analysis/scripts/validate-schema.py を作成してください。

仕様:
- 入力: data/current/ 配下の全JSONファイル（*-raw.txt は除外）
- 検証項目:
  1. 必須フィールドの存在確認: company, url, collectedAt, data, data.plans
  2. data.plans が空でないこと（1つ以上のプランがあること）
  3. 各プランの必須フィールド: name, price, priceValue, features, limitations
  4. priceValue が数値型（int または float）または null であること（「要問合せ」など金額が読み取れないプランは null を許容する）
  5. features と limitations がリスト型であること
- 出力: 検証結果をJSON形式で data/output/validation-report.json に保存
- 出力形式:
  {
    "validatedAt": "YYYY-MM-DDTHH:mm:ss",
    "results": [
      {
        "file": "ファイル名",
        "status": "pass" または "fail",
        "errors": ["エラーメッセージ1", "エラーメッセージ2"],
        "warnings": ["警告メッセージ1"]
      }
    ],
    "summary": {
      "total": 3,
      "passed": 2,
      "failed": 1
    }
  }
- コマンドライン引数: --data-dir でデータディレクトリを指定（デフォルト: data/current/）
- 実行時にターミナルにも結果を表示すること（色付きで pass/fail を表示）
